# Kemokem private AI gateway — connector contract

Deploy migrations 0056 and 0057. Integrations → ChatGPT → Configure. Choose active mode, configure each connector's permissions separately, generate its own token, then enable the gateway. Keep credentials in local OS secret storage or the hosted connector's server-side secrets. Never place them in prompts, URLs or source.

Base: /api/v1/ai-gateway. Every connector call uses Authorization: Bearer TOKEN over trusted TLS. The gateway itself is REST; the local and hosted MCP adapters are separate clients to be created after deployment.

GET /status returns the active mode and scopes. GET /tools returns only operations permitted for that credential, with input JSON schema and approvalRequired. POST /invoke accepts {"operation":"projects.list","input":{}} for reads. For writes add a unique UUID requestId. The response is PENDING until a logged-in Kemokem owner reviews the immutable request in Integrations. GET /requests/:id returns its status and result to the same credential, subject to current scopes. A duplicate request ID with the same input returns the existing request; a changed input is rejected. Review must occur within 30 minutes. No connector can approve itself. A mode switch, permission removal, revocation or owner demotion prevents new requests and invalidates approval while authorization is absent. Already executing actions are not rolled back. Running or failed operations must be checked in Kemokem before retrying.

Operation categories: creators, projects, scenes, H3, LTX, long video, AutoGen, media inventory, saved analysis, bounded keyframes, GPU, generation, publishing drafts, thumbnails, scheduled publishing, analytics and social inbox. The tool catalog is the authoritative list. All writes require approval, including drafts. Gemini analysis is separately billable and needs existing Gemini configuration; no paid OpenAI calls are made. Keyframes are sampled locally using FFmpeg (4 timestamps, 64 MiB video limit); images use owned library IDs (2 MiB limit). The connector must decode returned base64 as MCP image content, not pass raw base64 to the model. Files must be available from the owning agent. New Gemini analyses can include a timestamped transcript of audible speech/lyrics. This is an AI estimate, not verified verbatim speech. Older analyses may not have transcripts; there is no standalone local Whisper worker. Gemini use requires owner approval and may be billable. No arbitrary filesystem access, worker URL changes, credential access, immediate publishing or destructive file/project operations.

Before use: verify database migration, build, bearer authorization, owner approvals, workspace isolation, revocation, duplicate IDs, media retrieval and supported provider capabilities. The scheduled upload cancellation operation only accepts still-SCHEDULED drafts. Do not treat a previously authenticated connector as continuously online.
