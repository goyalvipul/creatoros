# Private AI Gateway

Deploy migration 0056. Open Integrations → ChatGPT. Disabled by default. Choose Local or Hosted, enable required scopes and issue a separate token. Store the token in the MCP adapter secret store, never in source or chat. Use Authorization: Bearer TOKEN over HTTPS (or a trusted private TLS endpoint). GET /api/v1/ai-gateway/status verifies connectivity. Other endpoints: GET /projects, GET /videos, GET /videos/:id/analysis, POST /projects (title, optional brief), all relative to /api/v1/ai-gateway. POST creates a draft only; do not automatically retry. Rotate or revoke credentials in the UI. Inactive mode credentials are rejected. No MCP adapter is installed by this change. No publishing or GPU execution is exposed yet. Validate build, migration, authentication, cross-workspace isolation and mode switching before exposing the gateway publicly.
