# Dashboard hardware telemetry
The existing Production machines cards retain their layout and restart safety. CPU and GPU utilization appear above RAM and VRAM meters, with NVIDIA GPU core temperature alongside queue counts. Windows scanner agents use GetSystemTimes (200 ms sample), GlobalMemoryStatusEx and bounded read-only nvidia-smi in standard driver install paths. No extra service, generic command execution, or dependencies beyond existing x/sys. Hardware samples travel through the signed existing heartbeat and devices.load JSON; no migration. GPU metrics require exact unique RTX/GTX model match on the verified worker host. Duplicate models or unsupported sensors remain unknown. New agent samples are rejected after 90 seconds or invalid timestamps. Existing ComfyUI memory values remain fallback when hardware unavailable. Mac/non-Windows agents retain prior behavior. CPU package temperature is not collected because reliable standard Windows readings are not available; GPU core temperature is explicitly labeled. Agent heartbeat normally every 30 seconds; UI polls every 10. No fabricated values, no automatic restart or thermal actions.
