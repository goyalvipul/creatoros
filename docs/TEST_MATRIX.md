# Test matrix: spec scenarios T01-T35

Maps each "critical case" in [PRODUCT_SPEC.md](PRODUCT_SPEC.md) section 11 to the test that proves it, and says plainly where proof is partial.

**Where tests live**

| Suite                          | Location                                  | Run with                                                                                        |
| ------------------------------ | ----------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Unit (domain, connectors)      | `packages/domain`, `packages/connectors`  | `pnpm test:unit`                                                                                |
| Integration (real Postgres 17) | `tests/integration/test/*.test.ts`        | `pnpm test:integration` (starts a disposable Postgres container; needs Docker)                  |
| Go agent                       | `apps/scanner-agent/internal/*/*_test.go` | `pnpm test:agent`                                                                               |
| Browser E2E (desktop + 360px)  | `tests/e2e/specs`                         | `pnpm test:e2e` (builds the web app, starts API :4100 and web :3100 against a fresh database)   |
| Live-stack restart check       | `infra/scripts/restart-test.mjs`          | `pnpm restart-test` (manual: acts on the running Compose stack, so it is not part of CI)        |
| Capacity (opt-in)              | `tests/integration/test/capacity.test.ts` | `$env:CAPACITY_FILES=100000; pnpm test:integration -- capacity` (skipped when the var is unset) |

## What no automated test can prove

- Real Gmail, YouTube, Instagram, Facebook, TikTok, Postiz or Todo accounts. They are built, mock-tested and shown as "not configured" until credentials exist. See [EXTERNAL_PREREQUISITES.md](EXTERNAL_PREREQUISITES.md).
- Tailscale HTTPS end to end. The helper script is tested for output and reversibility only; enabling it needs your tailnet's HTTPS setting.
- Windows service installation of the agent as a boot service, and SMB share access under a service account. The Go code cross-compiles and unit-tests; installation is a manual step in [OPERATIONS.md](OPERATIONS.md).
- Behaviour with your real terabytes of media. The capacity test uses synthetic rows; see the measured numbers in [FEATURES.md](../FEATURES.md).
