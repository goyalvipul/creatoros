# TikTok setup

Status: **not built; messaging unsupported.** No general DM API is known to be available to ordinary developer apps, and a data export is not a live inbox. Use the native TikTok inbox (link on the TikTok page in Socials), and log leads and follow-ups manually in CreatorOS.

If you want account/video info later, register an app at the TikTok developer portal and request `user.info.basic` and `video.list`; direct posting requires audit approval. Verify against the current TikTok docs before building.
